# vuln-lab

Учебный стенд для практики управления уязвимостями.

Проект завершен. Реализовано:
- [x] Развёрнут уязвимый стенд в Docker: OWASP Juice Shop и DVWA с базой данных
- [x] Проведено автоматическое сканирование (OWASP ZAP - пассивное и активное)
- [x] Написан кастомный парсер отчётов ZAP на Python (переводит сырой JSON в приоритизированную Markdown-сводку)
- [x] Проведён ручной поиск уязвимостей через Burp Suite и составлен подробный баг-репорт (Open Redirect)

## Артефакты проекта
* `zap_parser.py` — скрипт для обработки отчётов сканера ZAP.
* `reports/` — результаты работы сканера и сгенерированные сводки находок.
* `bug-report.md` — детальный отчёт об уязвимости Open Redirect, найденной вручную.


## Запуск

```bash
docker compose up -d
```

Juice Shop: http://localhost:3000
DVWA: http://localhost:4280 (admin / password)

Приложения намеренно уязвимы и доступны только с локального компьютера.
