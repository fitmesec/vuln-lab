# vuln-lab

Учебный стенд для практики управления уязвимостями.

Проект в работе. План:
- [x] Стенд в Docker: OWASP Juice Shop и DVWA с базой данных
- [ ] Автоматическое сканирование (OWASP ZAP)
- [ ] Парсер отчётов сканера на Python
- [ ] Ручной поиск уязвимостей и баг-репорт

## Запуск

docker compose up -d

Juice Shop: http://localhost:3000
DVWA: http://localhost:4280 (admin / password)

Приложения намеренно уязвимы и доступны только с локального компьютера.
